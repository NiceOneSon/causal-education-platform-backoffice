# 시나리오: 메뉴 이동 → iframe 안 화면 이동 → 뒤로 가기 두 번

CLAUDE.md 규칙 4(이동 기록은 iframe만 남긴다)를 검증한다. 규칙 4가 깨지면 이 테스트가 실패해야 한다.

## 단계
1. 껍데기 앱에 처음 들어온다. iframe은 기록 없이 열린다.
2. 왼쪽 메뉴에서 항목 A를 고른다. iframe이 A 화면으로 이동한다.
3. iframe 안에서 링크를 눌러 A 안의 다른 화면 A2로 이동한다.
4. 뒤로 가기를 한 번 누른다.
5. 뒤로 가기를 한 번 더 누른다.

## 기대 결과
- 4단계 후: iframe은 A 화면을 보여 준다.
- 5단계 후: iframe은 처음 들어왔을 때의 화면을 보여 준다.
- 매 단계에서 주소창은 iframe 화면과 맞춰져 있다.
- 껍데기가 history.pushState를 부르면(기록이 중복되면) 뒤로 가기 횟수와 화면이 어긋나 실패한다.
